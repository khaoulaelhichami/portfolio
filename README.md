
# Portfolio — Khaoula Elhichami

Site portfolio moderne pour présenter le CV, la photo de profil et les projets réalisés.

## Fichiers à ajouter

- `profile.jpg` : votre photo de profil, à placer à la racine du site.
- `cv.pdf` : votre CV téléchargeable.
- `images/parascolaire.png` : capture du projet parascolaire.
- `images/salle-sport.png` : capture du projet salle de sport.
- `images/employees.png` : capture du projet gestion employés.

## Lancer le site

Ouvrez `index.html` dans votre navigateur ou publiez le dossier sur GitHub Pages.

## Déploiement GitHub Pages

1. Envoyez les fichiers sur un dépôt GitHub.
2. Activez GitHub Pages sur la branche `main` et le dossier racine.
3. Attendez la génération du site.
